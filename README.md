# 💰 Full Stack Expense Tracker

## 📌 Project Overview
This is a **Full Stack Expense Tracker Web Application** built using **Java, JSP, Servlets, and MySQL**.  
It allows users to manage their daily expenses efficiently by adding, viewing, updating, and deleting expense records in a secure session-based system.
 
 - Project Type: **Full Stack Java Web Application**

---

## 🚀 Features

### 🔐 Authentication System
- User Registration
- Login / Logout functionality
- Forgot Password feature
- Session management for security

### 💸 Expense Management
- Add new expenses
- View all expenses
- Delete expenses
- Categorize expenses

### 📊 Dashboard
- Personalized user dashboard
- Dynamic greeting (Morning / Afternoon / Evening)
- Quick overview of expenses

---

git clone https://github.com/your-username/fullstack-expense-tracker.git

## ⚙️ Setup Instructions

### 1. Import Project
- Open IntelliJ IDEA / Eclipse
- Import as **Maven / Java project**

---

### 2. Configure Database
- Create a MySQL database
- Import required tables (if provided)
- Update database credentials in DAO files

---

### 3. Run on Server
- Configure **Apache Tomcat 10+**
- Deploy the project on server
- Start server

👉 Open in browser:
http://localhost:8080/myproject
